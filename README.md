# Exercícios de Listas em Python

Projeto com 20 exercícios independentes sobre listas em Python.

## Conteúdo

1. Criação e acesso a elementos
2. Percorrimento e filtro
3. Soma sem `sum()`
4. Média
5. Maior e menor sem `max()` e `min()`
6. Contagem de pares e ímpares
7. Busca sem `index()`
8. Posição de um elemento sem `index()`
9. Inserção e remoção
10. Ordenação
11. Fatiamento (slicing)
12. Remoção de repetidos sem `set()`
13. Valores acima da média
14. Compreensão de listas
15. Listas paralelas
16. Matriz 3x3
17. Segundo maior sem `sort()`
18. Frequência dos elementos
19. Controle de estoque
20. Análise de vendas

Cada arquivo pode ser executado separadamente com Python 3.
